AMK API Documentation

Comprehensive API reference for the AMK Management System.

Base URL: http://localhost:8080 (Development)
Authentication: All endpoints (except Auth) require a Bearer Token.
Header: Authorization: Bearer <token>

1. Authentication

Endpoints for user authentication and session management.

Method Endpoint Description
POST /auth/login Login to get JWT token
POST /auth/forgot-password Request password reset (sends OTP)
POST /auth/verify-otp Verify OTP code
POST /auth/reset-password Reset password using OTP

2. User Management

Management of system users, roles, and permissions.

Table: users

Method Endpoint Description Permission
POST /users/ Create new user user.create
GET /users/ Get all users user.read
GET /users/:id Get user by ID user.read
PUT /users/:id Update user user.update
DELETE /users/:id Delete user user.delete

Table: roles

Method Endpoint Description Permission
POST /users/roles/ Create new role role.create
GET /users/roles/ Get all roles role.read
PUT /users/roles/:id Update role role.update
DELETE /users/roles/:id Delete role role.delete

Table: permissions

Method Endpoint Description Permission
POST /users/permissions/ Create permission permission.manage
GET /users/permissions/ Get all permissions permission.manage
POST /users/permissions/assign Assign permission to role permission.manage
POST /users/permissions/revoke Revoke permission from role permission.manage

5. Salary Slips

Management of salary slips, including upload, draft review, and finalization.

Table: hc_temp_slip_gaji (Drafts)

Method Endpoint Description Permission
POST /hcgs/slip-gaji/upload Upload Excel to create drafts slipgaji.upload
GET /hcgs/slip-gaji/draft/:batchID Get drafts by batch slipgaji.upload
PUT /hcgs/slip-gaji/draft/:id Update draft item slipgaji.upload
POST /hcgs/slip-gaji/submit/:batchID Finalize drafts to main table slipgaji.upload

Table: hc_final_slip_gaji (Final)

Method Endpoint Description Permission
GET /hcgs/slip-gaji/ Get all final slips slipgaji.read_all
GET /hcgs/slip-gaji/me/history Get my slip history -
GET /hcgs/slip-gaji/me/view View my slip (HTML) -
GET /hcgs/slip-gaji/me/download Download my slip (PDF) -
GET /hcgs/slip-gaji/:id/view View any slip (HTML) slipgaji.view
GET /hcgs/slip-gaji/:id/download Download any slip (PDF) slipgaji.download
DELETE /hcgs/slip-gaji/:id Delete final slip slipgaji.delete

Upload & Draft Workflow

// 1. Upload Excel
POST /hcgs/slip-gaji/upload
Content-Type: multipart/form-data
Body: file=(binary), tipe_slip="driver_operator"

// 2. Review Drafts
GET /hcgs/slip-gaji/draft/{batch_id}

// 3. Fix Invalid Slips
PUT /hcgs/slip-gaji/draft/{id}
{ "nrp": "CORRECT_NRP" }

// 4. Submit Batch
POST /hcgs/slip-gaji/submit/{batch_id}
